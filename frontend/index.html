Discord connection

Not connected

The bridge controls self-mute through Discord desktop's local RPC connection. It does not simulate a keypress.

  1. Create an application in the Discord Developer Portal.
  2. Add the exact Discord account signed in to the desktop app under App Testers. Discord rejects the required RPC voice scope for other accounts.
  3. Add the OAuth redirect URI http://localhost.
  4. Paste the Client ID and Client Secret above, then approve the prompt in Discord desktop.
